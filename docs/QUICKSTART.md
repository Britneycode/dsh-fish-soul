# 从零跑起来

照着这五步做，大约 20 分钟能让"她"在 QQ 里回你第一句话。每一步后面都写了**怎么确认这步成了**，卡住时先看那句，再往下看「卡住了」。

想先知道她能干什么，看 [README 的能力表](../README.md#能力)；这里只管"怎么配起来"。

---

## 0. 先确认前置条件

- **Node ≥ 22.5**（命令行跑 `node -v`）。她靠 Node 自带的 SQLite 存记忆，低版本起不来。
- **DSH 桌面端**已装好、能正常打开（插件是装在 DSH 里的）。
- **一个能用的大模型**，在 DSH 里配好。她说话、排日程、整理记忆全靠它。
- 只有想接抖音时才需要 **一台常开的 Windows 桌面**（抖音走专用浏览器）。

## 1. 装插件

```
dsh plugin --profile desktop add dsh-fish-soul
```

**怎么确认成了**：重启 DSH，左侧栏出现「鱼」。六类设置页也能打开（记忆 / 角色 / 日常 / 平台 / 模型 / 系统）。

第一次打开会自动切到「使用引导」页，那里有 7 个步骤和完成状态 —— 后面的步骤跟它一致，可以对照着看。

## 2. 配模型

「模型 → 功能模型」。

每一项都可以留空，留空就是**跟 DSH 默认模型**。想省钱可以单独给「聊完记一下」「排日程」这类后台任务换个便宜模型 —— 这些不参与聊天，慢一点没关系。

**怎么确认成了**：这一页不再出现「DSH 里还没配模型」的警告。有警告说明 DSH 自己就没有可用模型，去 DSH 的设置里配。

## 3. 接 QQ

她要回 QQ 消息，得先有个"登录着 QQ 的机器人账号"帮你收发 —— 这个角色由 **SnowLuma** 扮演，插件通过 OneBot 11 正向 WebSocket 连它。

**SnowLuma 那一侧**：开一个 WS 服务，`role` 选 `Universal`，记住端口和 accessToken。默认是 `3001`。

**插件这一侧**：「平台 → QQ」

| 填什么 | 说明 |
|---|---|
| QQ 接入 | 打开 |
| SnowLuma 地址 | `ws://127.0.0.1:3001`，端口跟 SnowLuma 里那个对齐 |
| 访问令牌 | 跟 SnowLuma 里的 accessToken **填成一样的**。SnowLuma 那边设了就必须填，没设就两边都留空 —— 一边有一边没有是对不上的 |
| 主人 QQ | 你自己的 QQ 号。她靠这个认"你是谁"，见下面第 4 步 |

**怎么确认成了**：这一页顶部的状态条从「连接中」变成「**你的昵称 · N 位好友**」。

如果显示的是红字错误，那行字就是原因（端口没起、令牌不一致、SnowLuma 没登录）。改完参数会自动重连，不用重启插件。

## 4. 先私聊，别一上来就进群

用你自己的 QQ 点她私聊，随便说句话。

**怎么确认成了**：她回了。

没回的话按顺序查这三条：

1. **是不是好友**：非好友私聊她只记不答（这是故意的，防陌生人骚扰）。
2. **主人 QQ 填对没有**：填错不会让她不回话，但「（主人）」标签、`/鱼` 命令、主动开口都会算错人 —— 她不知道该找谁说话。所以别空着，也别填成机器人自己那个号（两个号很像，最容易填反）。**第一次就填对**：填过之后再改号有个已知问题（可能变成整条 QQ 通道都不回），要换号先去群里说一声。
3. **模型配了没**：见第 2 步。

## 5. 再进群（这里最容易以为"插件坏了"）

**群默认是拒绝的**：`只在这些群` 空着、`所有群` 没开，那**任何群她都不说话**。这是护栏，不是 bug。

两种开法，选一种：

- 「只在这些群」填群号（多个用逗号或空格隔开，纯数字就行）—— 推荐。
- 打开「所有群」—— 任何群里 @ 她都会回。

**开了白名单还不够**：群里她**只听点名** —— @ 她，或者叫她的名字（人格卡名字，两个字以上）。也可以打开「点名后接着听」，这样被叫到之后她能顺着聊几句，不用每句都 @。

**怎么确认成了**：在群里 @ 她一句，她回了。

## 卡住了

### 设置页打不开

| 现象 | 意思 | 怎么办 |
|---|---|---|
| **HTTP 404** | 插件后台根本没加载 | 确认插件装进了当前 profile。宿主日志里搜 `[fish-soul] 启动闸门已挂` |
| **503「插件还在启动 / 插件启动失败，挂在第 N 步…」** | 插件加载了，但初始化没走完 | 是**真的启动失败**，不是慢。宿主日志里有 `[fish-soul] 启动失败：挂在第 N/M 步「…」` 和堆栈，那句话就是卡点 |

走完会打 `[fish-soul] 路由已挂`。搜不到这行就是没起来。

### 她能连上，但某些能力"没反应"

多数是**本来就没开**，不是坏了：

- 语音（听 / 说）
- 向量检索（不配也能用，只是想起事情靠关键词匹配，没那么准）
- 联网查
- B站 / 抖音的点赞、收藏、发动态、回评论、自己刷视频

这些默认全关，要一个个去设置页打开。改完一般立刻按新配置走；如果看不出来，先看那页有没有状态或报错，再考虑重启宿主。

### 数据存在哪

都在 `$DSH_HOME`（默认 `~/.dsh`）下：设置是 `fish-soul-config.json`，记忆是一个 SQLite `fish-soul/soul.db`。备份、人格卡、登录态也在这个目录，完整表见 [README](../README.md#配置与数据)。

**记忆和设置都在本机、未加密**，删之前先备份。
